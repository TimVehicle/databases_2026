## Отчёт: ветка `sem8-setup`

Ветка добавляет окружение для выполнения домашних заданий начиная с 8-ого. Существующие файлы репозитория не изменяются — добавлено 7 файлов в папке `hw/`.

**Что добавлено:**
- `hw/окружение/` — Скопированная папка из `СУБД_5\семинары\студентам\семинар_8\окружение`
- `hw/run.sh` — автоматическая сборка образа и запуск контейнера одной командой
- `hw/.gitattributes` — настройка LF для корректной работы скриптов на Windows
- `hw/.gitignore` — пустой файл

**Основные команды:**

Для запуска из папки `hw` в Git Bash выполнить:

```bash
bash run.sh
```

После запуска:
- JupyterLab: http://localhost:8888 (пароль `student`).
- PostgreSQL: `localhost:5432`, база `demo`, пользователь `postgres`.


Доп. команды:
```bash
docker logs -f seminar8 # Для просмотра логов

docker rm -f seminar8 # Для остановки и удаления контейнера

docker stop seminar8 # Для остановки контейнера

docker start seminar8 # Для повторного запуска после остановки
```
